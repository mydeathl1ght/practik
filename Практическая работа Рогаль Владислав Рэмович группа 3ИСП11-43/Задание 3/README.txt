Практическая работа №3: Подключение Flask и первый маршрут

Содержимое архива:
- app.py — Flask-приложение с маршрутами / и /about.
- templates/ — папка для HTML-шаблонов (пока пустая).
- answers.txt — ответы на контрольные вопросы.
- requirements.txt — зависимость Flask.

Как запустить:
1. Откройте терминал в папке проекта.
2. Установите Flask: python -m pip install -r requirements.txt
3. Запустите сервер: python app.py
4. Откройте http://127.0.0.1:5000
5. Проверьте http://127.0.0.1:5000/about
6. Для проверки 404 откройте http://127.0.0.1:5000/nonexistent
7. Для остановки сервера нажмите Ctrl+C.

Примечание: debug=True используется только для учебной разработки, не для публичного сервера.
