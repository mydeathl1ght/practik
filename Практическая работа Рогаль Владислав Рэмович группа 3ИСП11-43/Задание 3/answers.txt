Контрольные вопросы — Практическая работа №3

1. Декоратор @app.route('/') связывает URL главной страницы «/» с функцией index(). При запросе этого адреса Flask вызывает функцию.
2. GET используется для получения страницы или ресурса, а POST — для отправки данных на сервер, например из формы. По умолчанию маршрут Flask принимает GET.
3. debug=True включает автоматическую перезагрузку при изменении кода и подробные сообщения об ошибках. На реальном сервере его нельзя использовать из-за риска раскрытия отладочной информации и угроз безопасности.
4. 127.0.0.1 — адрес localhost, то есть текущего компьютера. 5000 — порт, на котором работает Flask-сервер.
5. Для /nonexistent не объявлен маршрут, поэтому Flask возвращает стандартный HTTP-ответ 404 Not Found.
6. Flask по умолчанию ищет HTML-шаблоны в папке templates рядом с приложением. Если назвать папку иначе, шаблоны не будут найдены без дополнительной настройки.
7. Второй сервер не сможет занять тот же порт, пока он используется первым. Обычно появится ошибка Address already in use; нужно остановить первый сервер или выбрать другой порт.
