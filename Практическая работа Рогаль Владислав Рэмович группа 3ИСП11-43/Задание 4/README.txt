Практическая работа №4
Интеграция Flask и SQLite (чтение данных)

Состав проекта:
- app.py — Flask-приложение, читает задачи из SQLite и передаёт их шаблону;
- templates/index.html — HTML-шаблон Jinja2;
- app.db — SQLite-база с примерами задач;
- init_db.py — создаёт таблицу tasks, если её нет;
- check_db.py — выводит таблицы и структуру tasks;
- crud_console.py — консольное добавление, просмотр, выполнение и удаление задач;
- requirements.txt — зависимости;
- answers.txt — ответы на контрольные вопросы.

Запуск:
1. Установи зависимость: python -m pip install -r requirements.txt
2. Запусти сайт: python app.py
3. Открой в браузере http://127.0.0.1:5000

На странице отображаются задачи из app.db. Выполненные задачи со статусом done зачёркнуты.
Чтобы проверить связь с базой, не останавливая Flask, открой второй терминал в папке task_manager,
запусти python crud_console.py и добавь задачу. Затем обнови страницу в браузере.

Если базы или таблицы нет, сначала запусти python init_db.py. В архив уже включена база
с несколькими примерами задач, поэтому приложение можно проверить сразу.


Контрольные вопросы: 
1. Зачем нужен шаблонизатор Jinja2, если можно вернуть HTML-строку из функции?

Jinja2 позволяет хранить HTML отдельно от Python-кода, упрощает чтение и редактирование страниц и позволяет подставлять данные в шаблон.

2. Чем {{ ... }} отличается от {% ... %} в Jinja2?

{{ ... }} используется для вывода значений, например {{ item.title }}. {% ... %} используется для управляющих конструкций, таких как циклы и условия.

3. Что делает render_template('index.html', items=rows)?

Находит файл index.html в папке templates, подставляет в него данные из rows под именем items и возвращает готовую HTML-страницу.

4. Почему при чтении данных не нужен conn.commit()?

Потому что при чтении с помощью SELECT данные не изменяются, поэтому сохранять изменения не требуется.

5. Что такое sqlite3.Row и почему item.title работает только с ним?

sqlite3.Row позволяет обращаться к значениям строки базы данных по именам столбцов, например item['title']. Благодаря этому в шаблоне можно использовать item.title вместо индексов кортежа.

6. Куда Flask кладёт файлы шаблонов по умолчанию и можно ли это изменить?

По умолчанию Flask ищет шаблоны в папке templates рядом с файлом приложения. Путь можно изменить при создании приложения с помощью параметра template_folder.

7. Что выведет шаблон, если items — пустой список?

Шаблон не покажет список задач, а выведет сообщение: «Список пуст. Добавь первую задачу!». Это происходит благодаря конструкции {% else %}.
