Ответы на контрольные вопросы — Практическая работа №5

1. POST отправляет данные в теле HTTP-запроса и используется для операций, меняющих данные на сервере. GET обычно используется для получения страниц и данных. Формы создания записей отправляют POST, чтобы не передавать вводимые данные в URL и явно обозначить изменение данных.

2. Если убрать methods=['GET', 'POST'], Flask по умолчанию разрешит только GET. При отправке формы методом POST сервер вернёт ошибку 405 Method Not Allowed.

3. Post/Redirect/Get нужен, чтобы после успешного POST перенаправить браузер на GET-страницу. Без редиректа обновление страницы может повторно отправить POST и создать дубликат задачи.

4. url_for('index') строит URL по имени функции маршрута. Если адрес маршрута изменится, ссылка продолжит работать без ручного изменения строки '/'.

5. request.form.get('title', '') вернёт пустую строку, если поля title нет, а request.form['title'] может вызвать BadRequestKeyError.

6. Серверная валидация нужна, потому что проверку required в браузере можно обойти. Сервер должен самостоятельно проверить данные до записи в базу.

7. Последовательность: получить POST-запрос → прочитать и проверить title → открыть соединение с БД → выполнить INSERT с параметром ? → вызвать commit() → закрыть соединение → redirect на GET → загрузить и показать список задач.
