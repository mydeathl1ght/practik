Практическая работа №2
Базовые CRUD-операции через консоль

Файлы:
- crud_console.py — консольное приложение;
- app.db — база SQLite с таблицей tasks;
- README.txt — инструкция и ответы на контрольные вопросы.

Запуск:
1. Распакуйте архив.
2. Откройте терминал в папке task_manager.
3. Выполните: python crud_console.py

Пункты меню:
1 — показать задачи; 2 — добавить; 3 — отметить выполненной;
4 — удалить задачу с подтверждением; 0 — выход.

Реализованы SELECT, INSERT, UPDATE и DELETE. Используются параметризованные
запросы с ?, проверка пустого названия и проверка id. Изменения сохраняются
через commit().

Ответы на контрольные вопросы:
1. Для SELECT commit() не нужен, так как данные только читаются. Для INSERT
   commit() нужен, чтобы сохранить изменение в базе.
2. fetchone() возвращает одну строку или None, если строк нет.
3. fetchone() получает одну строку, fetchall() — все строки результата.
4. (title,) — кортеж из одного элемента, запятая обязательна. (title) — строка
   в скобках, а не кортеж.
5. Если id не существует, после UPDATE rowcount будет 0.
6. isdigit() проверяет, что ввод состоит из цифр, и помогает избежать
   ValueError при преобразовании в int.
7. Параметризованные запросы отделяют ввод пользователя от SQL-кода, поэтому
   введённая строка обрабатывается как данные, а не как SQL-команда.
